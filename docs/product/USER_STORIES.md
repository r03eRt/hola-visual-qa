# User stories

- As a developer, I can run the critical page matrix before opening a PR.
- As a QA engineer, I can add a scenario without writing a duplicate test body.
- As an ad engineer, I can see whether a placement container existed, an ad request fired and content rendered.
- As a reviewer, I can inspect expected, actual and diff images before accepting a baseline change.
- As a maintainer, I can replace Claude with another provider without changing pass/fail logic.
- As a security owner, I can disable AI and ensure no evidence leaves the machine.
- As a developer, I can reproduce a failure from a saved trace and run manifest.
