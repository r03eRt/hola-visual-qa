# Visual QA skill

1. Read the feature SPEC and acceptance criteria.
2. Add or modify one isolated scenario or capability.
3. Use Playwright assertions for pass/fail.
4. Stabilize known dynamic elements narrowly with data attributes.
5. Capture console, page and request failures.
6. Use AI only to summarize evidence after a deterministic failure.
7. Run typecheck and the smallest relevant test set.
8. Never commit keys, auth state, reports or videos.
9. Put every feature in its own branch and PR.
