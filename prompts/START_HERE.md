# Prompt for a new coding agent

You are continuing the Hola Visual QA project. Read `AGENTS.md`, then `docs/CONTEXT.md`, `docs/STATUS.md`, the system architecture, relevant specs and roadmap. The repository is a starter, not a finished application.

Work on exactly one feature and one PR. Before coding, state the chosen roadmap item, its acceptance criteria, files expected to change and any unresolved dependency. Playwright and explicit checks own pass/fail; AI only explains failures. Never update snapshots automatically or weaken tests to make them pass. At completion, update status/documentation and provide a handover using `docs/handover/HANDOVER_TEMPLATE.md`.
